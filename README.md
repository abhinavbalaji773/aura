# Aura — AI Dining Menu

A premium hospitality menu experience for restaurants powered by **Aura**, an AI-integrated waiter assistant.

Built as a static web demo for **Rameshwaram Café** — warm cinematic UI, real food photography, mood-based browsing, and a conversational AI concierge.

## Preview

Open `index.html` in your browser (internet required for Unsplash images and fonts).

```bash
# Optional local server
python -m http.server 8080
```

## Stack

- HTML / CSS / JavaScript (no build step)
- [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) + [Satoshi](https://www.fontshare.com/fonts/satoshi)
- Unsplash photography

## Features

- Restaurant-branded header with Aura integration
- Mood categories, search, trending & weather recommendations
- Chef's special + image carousels
- Cart, favorites, and AI chat assistant
